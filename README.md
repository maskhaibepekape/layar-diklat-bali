# 📺 Layar Diklat – Pusdiklatwas BPKP Wilayah II Bali

Tampilan layar signage digital vertikal 1080×1920 Full HD untuk monitor lobby Balai Diklat BPKP Bali.

## 🌟 Fitur Utama
- **Tampilan Vertikal 1080×1920**: Sesuai orientasi TV Smart Signage.
- **Perputaran Otomatis (Auto-Loop)**: Menyajikan sambutan diklat aktif, informasi ruangan kelas/jam/peserta, catatan penting peserta, dan jadwal diklat mendatang.
- **Background Music (BGM)**: Audio latar instrumental dengan kontrol volume dan auto-loop.
- **Foto Gedung & Branding BPKP**: Identitas resmi BPKP GIA Corpu.
- **Responsif & Ringan**: Nol framework berat, pure HTML5/CSS3/JavaScript murni.

## 🛠️ Pemeliharaan Data
Data pelatihan diedit langsung pada blok `<script id="data" type="application/json">` di `index.html`.
